Knowledge Studio — FINAL (2026-09-13)

Что это
-------
Устанавливаемое local-first PWA для Android-планшета и телефона.
Структура: Курс → Урок → Тема → документ.

Установка на GitHub Pages
-------------------------
1. Создайте отдельный репозиторий, например knowledge-studio.
2. Загрузите ВСЕ файлы из этого ZIP в корень репозитория.
3. Settings → Pages → Deploy from branch → main / root.
4. Откройте адрес вида https://username.github.io/knowledge-studio/
5. В Chrome: ⋮ → «Установить и создать ярлык» → «Установить».

Данные
------
Курсы/уроки/темы/документы хранятся в IndexedDB. PDF сохраняются в OPFS, если браузер его поддерживает, иначе используется локальный fallback. Данные не отправляются на сервер.

PDF
---
Импорт работает локально, без AI. Оригинальный PDF сохраняется. Встроенный автономный парсер консервативный: хорошо работает с рядом обычных текстовых PDF, но сложные subset-шрифты, сканы, формулы, таблицы и многоколоночная верстка могут извлекаться неполно. В таких случаях приложение сохраняет оригинал и не выдумывает содержание. Для проверки можно открыть исходный PDF из импортированного блока.

Темы
----
Встроено 20 визуальных families. Есть Dark / Light / System и независимый Paper Reader.

Backup
------
Настройки → Резервные копии → Экспорт backup. Формат — ZIP без внешних зависимостей; включает библиотеку и сохранённые PDF.

Ограничение текущей сборки
-------------------------
Из-за отсутствия сетевого доступа к npm/CDN в среде сборки внешние runtime-библиотеки из исследовательской спецификации (Tiptap/ProseMirror, PDF.js, Dexie, MiniSearch, Workbox, zip.js, KaTeX) не могли быть безопасно загружены и зафиксированы локально. Поэтому эта поставка реализована без runtime CDN на нативных Web API: собственный блочный редактор, IndexedDB/OPFS, локальный Worker-поиск, автономный PDF text extractor и ZIP reader/writer. Основной пользовательский функционал работает без внешней сети, но PDF-извлечение менее универсально, чем полноценный PDF.js.

Безопасность
------------
CSP self-only, нет runtime CDN, пользовательский текст выводится через экранирование, PDF JavaScript не выполняется, backup проверяет пути, восстановление валидирует формат.

PDF.JS
------
В этот релиз локально включён официальный PDF.js 6.3.289 (Mozilla), Apache License 2.0.
Файлы находятся в vendor/pdfjs/. Копия лицензии: vendor/pdfjs/LICENSE.
Runtime-CDN не используется. pdf.mjs и pdf.worker.mjs работают локально; CMaps, standard_fonts и WASM также упакованы для сложных PDF и кэшируются Service Worker по мере использования.
Импорт не использует AI и не переписывает содержание. PDF.js извлекает текстовые элементы и их геометрию; Knowledge Studio эвристически восстанавливает строки, заголовки, списки и возможные колонки и сохраняет привязку блока к странице/прямоугольнику источника.
Сканы без текстового слоя требуют OCR, которого в текущем релизе намеренно нет.
