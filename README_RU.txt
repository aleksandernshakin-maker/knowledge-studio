Knowledge Studio — локальная сборка 2026-09-14

Существующее vanilla JS приложение. Структура: Library → Course → Lesson → Topic → blocks.
Новый проект, framework и runtime CDN не требуются. Публикация в этой работе не выполнялась.

Запуск и проверки
-----------------
Из корня существующего репозитория:
  node tests/check.mjs
  python -B tests/serve.py --port 8766
Открыть http://127.0.0.1:8766/knowledge-studio/tests/runtime.html
Подробный порядок дополнительных проверок: tests/README.md.
Тесты выполняются на отдельном localhost-origin, не на рабочей библиотеке GitHub Pages.

GitHub Pages
------------
Сохраняйте существующий репозиторий и публикацию из его корня. Все модули, worker,
manifest, иконки и vendor/pdfjs должны публиковаться вместе. Пути относительные;
локальный сервер воспроизводит /knowledge-studio/. При изменении app shell нужно
повышать VERSION в sw.js. Новая версия предлагает применить обновление после
сохранения Editor. Автоматической очистки IndexedDB при обновлении нет.

Данные и восстановление
----------------------
IndexedDB knowledge-studio, schema 4, 12 stores. Миграция добавляет отсутствующие
stores, сохраняя существующие записи. PDF оригиналы: OPFS или IndexedDB Blob fallback.
Сохранение документа и связанных данных атомарно; конфликт изменений другой вкладки
отклоняется. Editor сохраняет локальный черновик и историю последних 12 редакций.
Черновик/историю можно восстановить отдельной темой, сохранив текущую версию.
Корзина скрывает удалённых родителей и их потомков из каталогов и поиска.

PDF.js
------
Полный локальный Mozilla PDF.js 6.3.289, Apache 2.0, vendor/pdfjs/LICENSE.
Модуль загружается при обращении к PDF. Worker, CMaps, standard_fonts и WASM
находятся в vendor/pdfjs и входят в offline-кэш. Исходный PDF открывается canvas
просмотрщиком PDF.js; извлечённые блоки сохраняют source/page/rect provenance.
Реконструкция структуры текста эвристическая. Для сканов без текста выводится
предупреждение; OCR намеренно отсутствует. AI и сетевые модели отсутствуют.

Оформление
----------
32 визуальные темы, Dark/Light/System, независимый Reader Follow/Paper/Sepia/OLED.
Сохранена navy/glass/blue-violet дизайн-система, SVG visual worlds и пользовательские
обложки курсов. Визуальные темы доступны в настройках на узких экранах.
Reduced Motion учитывает настройку приложения и предпочтение ОС.

Backup
------
Настройки → Экспорт backup / Импорт backup. ZIP включает структуру, документы,
настройки, историю, встроенные изображения и все оригинальные PDF.
Формат v2: CRC ZIP и SHA-256 библиотеки/PDF; чтение прежнего v1 сохранено.
Неполный или повреждённый архив отклоняется. Restore выполняется одной транзакцией.
Отсутствие обязательного PDF блокирует экспорт, вместо ложного сообщения об успехе.
ZIP32: архивы >=4 ГБ и >=65535 записей отклоняются явно; объём также ограничен
доступной памятью и квотой браузера. Регулярно сохраняйте backup вне браузера.
